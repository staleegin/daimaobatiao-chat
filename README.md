# daimaobatiao-chat · 呆猫八条 AI 表情包聊天包

让你的 AI 用「八条」的脾气聊天：话不多、爱开玩笑、有点小脾气、会阴阳怪气，也会撒娇装可爱，并且每条回复都会配一张八条或淑熊的表情包。

- 作者：呆猫八条（抖音号 3086296040）
- 表情包：187 张（静态 141 张、动图 46 张）
- 角色：八条（银渐层小猫）、淑熊（金丝熊，不是棕熊）

## 仓库里有什么

| 文件 | 用途 |
|---|---|
| `SKILL.md` | Claude 技能文件：角色设定、说话规则、选表情规则 |
| `prompt.md` | 通用版提示词，已附上全部表情清单，可以直接粘贴到 ChatGPT、DeepSeek 或第三方客户端 |
| `stickers.json` | 表情索引：编号、角色、画面、意思、情绪标签、图片链接 |
| `stickers/` | 表情图片，S 开头是静态图，D 开头是动图 |

## 怎么用

### Claude

把整个仓库下载下来，作为技能（Skill）添加到 Claude 里，`SKILL.md` 和 `stickers.json` 要放在同一个文件夹。之后跟 Claude 说「用八条的语气陪我聊天」就会生效。

### ChatGPT（自定义 GPT）

1. 新建一个 GPT，把 `prompt.md` 的全部内容粘贴到「Instructions」。
2. 开始聊天。

注意：ChatGPT 官方网页经常不显示外链图片，你可能只会看到一行图片链接。想看到图，请用下面的第三方客户端方式。

### DeepSeek / ChatGPT 的 API + 第三方客户端（推荐）

Cherry Studio、LobeChat、ChatBox 这类客户端会把回复里的图片链接直接显示成图片，效果最好。

1. 在客户端里填好 DeepSeek 或 OpenAI 的 API Key。
2. 新建一个助手或角色，把 `prompt.md` 的全部内容粘贴到「系统提示词」。
3. 开始聊天。

### DeepSeek 官网

官网没有「技能」或「系统提示词」功能，只能每次新对话开头先把 `prompt.md` 的内容粘贴进去。能不能显示图片，取决于官网当时是否渲染外链图片。
