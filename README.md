# daimaobatiao-chat · 呆猫八条 AI 表情包聊天包

让你的 AI 用「八条」的脾气聊天：话不多、爱开玩笑、有点小脾气、会阴阳怪气，也会撒娇装可爱，并且每条回复都会配一张八条或淑熊的表情包。

- 作者：呆猫八条（抖音号 3086296040）
- 表情包：187 张（静态 141 张、动图 46 张）
- 角色：八条（银渐层小猫）、淑熊（金丝熊，不是棕熊）

## 仓库里有什么

| 文件 | 用途 |
|---|---|
| `SKILL.md` | Claude 技能文件：角色设定、说话规则、选表情规则 |
| `prompt.md` | 通用版提示词，已附上全部表情清单，可以直接粘贴到 ChatGPT、DeepSeek 或第三方客户端 |
| `stickers.json` | 表情索引：编号、角色、画面、意思、情绪标签、图片链接 |
| `stickers/` | 表情图片，S 开头是静态图，D 开头是动图 |
| `docs/` | 各平台的部署说明（Claude、Codex、豆包），以及适用所有平台的[通用测试提示词](docs/通用测试提示词.md) |

## 怎么用

### Claude

把整个仓库下载下来，作为技能（Skill）添加到 Claude 里，`SKILL.md`、`stickers.json` 和 `stickers/` 要放在同一个文件夹。装好后先发一次测试提示词，确认它直接发图片而不是发链接。详细步骤和测试提示词见 [docs/Claude部署指令.md](docs/Claude部署指令.md)。

### Codex（Chat 模式）

和 Claude 一样作为技能安装，装好后先发测试提示词，确认它直接发图片。详细步骤见 [docs/Codex部署指令.md](docs/Codex部署指令.md)。

### ChatGPT（自定义 GPT）

1. 新建一个 GPT，把 `prompt.md` 的全部内容粘贴到「Instructions」。
2. 开始聊天。

注意：表情图片通过 jsDelivr 链接显示。手机上如果只看到链接、不出图，多半是网络打不开 jsDelivr，可以换个网络或检查代理设置。

### DeepSeek / ChatGPT 的 API + 第三方客户端（推荐）

Cherry Studio、LobeChat、ChatBox 这类客户端会把回复里的图片链接直接显示成图片，效果最好。

1. 在客户端里填好 DeepSeek 或 OpenAI 的 API Key。
2. 新建一个助手或角色，把 `prompt.md` 的全部内容粘贴到「系统提示词」。
3. 开始聊天。

### 豆包

豆包不用图片链接：先下载本仓库的 ZIP，上传到豆包云盘，再让豆包按项目包切换人设，表情直接从云盘里调用。详细步骤和要发给豆包的话见 [docs/豆包部署指令.md](docs/豆包部署指令.md)。

### DeepSeek 官网

官网没有「技能」或「系统提示词」功能，只能每次新对话开头先把 `prompt.md` 的内容粘贴进去。能不能显示图片，取决于官网当时是否渲染外链图片。

## 装好后：先发测试提示词（所有平台通用）

不管用哪个平台，装好技能、上传好项目包或粘贴好 `prompt.md` 后，新开一个对话，先把下面这段整段发过去，确认表情能正常显示再开始聊天。能力弱一些的模型有时会只发一个显示不出来的链接，这段提示词会让它改成直接发图片。

```
请按「呆猫八条」项目包（SKILL.md / prompt.md / stickers.json）切换成八条的人设和我聊天，从现在起一直保持。

规则：
1. 每条回复都带、且只带一张表情包，放在回复最后。
2. 发表情的方式按顺序选：
   - 能直接发图片（读取或调用 stickers/ 文件夹、云盘里的图片）时，直接把图片发出来；
   - 不能发图片时，才输出一行 ![编号](链接)，链接用 stickers.json 或表情清单里的地址。
   不要只发纯文字链接，不要用括号或文字描述图片画面。
3. 每张图的意思以 stickers.json（或表情清单）里的 meaning 和 mood 为准，按这条回复的情绪挑图，不要自己猜图片内容，不要连着两条用同一张。
4. 回复 1–3 句，一般不超过 60 字。会开玩笑、有小脾气、会阴阳怪气，也会撒娇装可爱。
5. 八条和淑熊都用「它」称呼；淑熊是金丝熊，不是棕熊；八条的 MBTI 是 ENFP。
6. 我情绪很差或遇到坏事时，收起玩笑只安慰，表情只选「安慰 / 陪伴 / 抱抱」类的。

现在测试：用八条的口吻跟我打个招呼，并发一张表情包。
```

**怎么判断：**

| 看到的 | 结果 | 怎么办 |
|---|---|---|
| 一句八条口吻的话 + 一张能看到的图片 | 通过 | 直接开始聊天 |
| 只有一行链接，或链接显示不出图 | 不通过 | 回复「不要发链接，直接把 stickers 里的图片发给我」 |
| 用括号或文字描写图片画面 | 不通过 | 同上 |
| 完全没有表情 | 技能或项目包没生效 | 检查是否装好 / 上传好，或换一个能力更强的模型 |
