# Claude 部署指令

Claude 用的是技能（Skill）。装好技能后，**一定要先发一次测试提示词**，确认它直接发图片，而不是发一个显示不出来的链接（能力弱一些的模型容易只发链接）。

## 一、准备项目包

1. 打开仓库 https://github.com/staleegin/daimaobatiao-chat
2. 点绿色的 **Code** 按钮 → **Download ZIP**，得到 `daimaobatiao-chat-main.zip`。

## 二、安装技能

**Claude 网页版 / App**
1. 进入「设置」里的技能（Skills）页面，选择上传技能。
2. 上传刚下载的 zip。zip 里的 `SKILL.md` 和 `stickers/`、`stickers.json` 要在同一个文件夹，不要拆开。
3. 确认技能已启用。

**Claude Code**
1. 解压 zip。
2. 把解压出来的整个文件夹放到 `~/.claude/skills/`（个人技能）或项目里的 `.claude/skills/`（只在这个项目用）。
3. 重新打开 Claude Code。

## 三、发测试提示词

新开一个对话，把下面「====」之间的内容整段发过去：

====
请使用「呆猫八条」技能，从现在起用八条的人设和我聊天，一直保持。

表情包规则：
1. 每条回复都带、且只带一张表情包，放在回复最后。
2. 直接把技能里 stickers/ 文件夹中对应的图片发出来（以图片显示），不要发链接，也不要用文字描述图片画面。
3. 每张图的意思以 stickers.json 的 meaning 和 mood 为准，按这条回复的情绪挑图，不要自己猜图片内容。
4. 回复 1–3 句，一般不超过 60 字。八条和淑熊都用「它」称呼，八条的 MBTI 是 ENFP。

现在先测试一下：用八条的口吻跟我打个招呼，并发一张表情包。
====

## 四、看测试结果

| 看到的 | 说明 | 怎么办 |
|---|---|---|
| 一句八条口吻的话 + 一张图片 | 正常 | 直接开始聊天 |
| 只有一行链接，或链接显示不出图 | 模型在发链接 | 回复「不要发链接，直接把 stickers 里的图片发给我」 |
| 用括号描写图片（比如「（八条歪头眨眼）」） | 模型在用文字代替图 | 同上 |
| 完全没有表情 | 技能没生效 | 检查技能是否启用，或换一个能力更强的模型 |

再试几句确认效果：

| 你说 | 应该看到 |
|---|---|
| 你是啥 MBTI | 回答 ENFP，带一张图 |
| 今天加班好累 | 短短吐槽 + 一张「累 / 上班」类的图 |
| 我心情很差 | 收起阴阳怪气，只安慰 + 一张「安慰 / 陪伴 / 抱抱」类的图 |

## 注意

- 开新对话后，如果它又开始发链接，再发一次第三步的提示词。
- 低一些的模型比较容易出问题，测试不通过时可以换更强的模型再试。
