桌宠（Mac / Windows / 安卓）

让八条住进你的屏幕：会散步、蹦跳、呼吸，可以摸摸、喂小鱼干，没人理就自己睡觉。

怎么玩

  • 单击摸摸（连着摸太多次它会生气）
  • 双击喂小鱼干
  • 按住拖动把它拎起来，松手会掉下去
  • 右键：睡觉 / 叫醒、待在原地、大小、每小时提醒休息、退出
⬇ 下载桌宠（Mac） ⬇ 下载桌宠（Windows） ⬇ 下载桌宠（安卓）

Mac：约 2.5MB · 支持 Apple 芯片和 Intel · macOS 12 及以上
Windows：约 74MB（自带运行环境，双击就能用）· Windows 10 / 11 64 位
安卓：约 5.4MB · 安卓 8 及以上（iPhone 不支持）

Mac：打开和关闭
  1. 双击下载好的 BatiaoPet.dmg，在弹出的窗口里把「八条桌宠」拖到旁边的「应用程序」文件夹，再从「应用程序」里双击打开。它没有程序坞图标，屏幕上只有八条本身。
  2. 第一次打开提示「无法验证开发者」时：打开「系统设置 → 隐私与安全性」，找到「八条桌宠」的提示，点「仍要打开」。
  3. 关闭：在八条身上右键 → 退出。找不到它时，在「活动监视器」里搜索 BatiaoPet 结束，或在终端输入 pkill -x BatiaoPet。
  4. 不会开机自启，需要的话在「系统设置 → 通用 → 登录项」里添加。
Windows：打开和关闭
  1. 下载 BatiaoPet.exe，放到任意文件夹（比如「文档」），双击打开。它没有任务栏图标，屏幕上只有八条本身，会落在任务栏上方活动。
  2. 第一次打开弹出蓝色的「Windows 已保护你的电脑」时：点「更多信息」→「仍要运行」。
  3. 关闭：在八条身上右键 → 退出。找不到它时，打开「任务管理器」，找到 BatiaoPet 结束任务。
  4. 想开机自启：按 Win + R，输入 shell:startup 回车，把 exe 的快捷方式放进打开的文件夹。
  5. 设置保存在 %APPDATA%\BatiaoPet，删掉 exe 和这个文件夹就卸载干净了。
安卓：安装和关闭
  1. 在手机浏览器里下载 BatiaoPet.apk，点它安装。提示「未知来源」时，按提示允许这一次安装。
  2. 打开「八条桌宠」，点「让八条出来」。在弹出的悬浮窗列表里找到「八条桌宠」，打开「显示在其他应用上层」，再返回。
  3. 单击摸摸、双击喂小鱼干、按住拖动；长按打开设置页（睡觉、待在原地、大小、提醒休息）。
  4. 关闭：在 App 里点「让八条回去」，或在通知栏「八条在陪你」上点「退出」。
  5. 过一会儿就不见了：在设置页点「电池不限制」，再按设置页里的说明给它开「自启动」/「允许后台运行」（小米、华为、OPPO、vivo 位置不同）。
